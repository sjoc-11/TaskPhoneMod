# TaskPhone Mod

## Ever lost track of what you were doing in Minecraft?

You're playing with your friends. Someone says "hey, go get 64 blocks of stone while I build the walls." You say "yeah sure, on it." Then someone cracks a joke on Discord, the conversation keeps going, and 20 minutes later you're punching a cow in a field somewhere with no memory of what you were supposed to be doing.

Your friend comes back and asks "where's the stone?" and you just stand there. We've all been there.

Or maybe you're working on a big project, you know exactly what needs to be done, but you keep losing track of the steps. Was it 64 stone or 64 cobblestone? Did they say the north wall or the east wall? You end up running back and forth, wasting time, forgetting half the list.

## A checklist that lives inside your game

TaskPhone is a simple mod that adds a craftable phone to Minecraft. Right-click it and a checklist opens up. Write down what you need to do, and when you finish something, mark it as done. That's it. No complicated menus, no overwhelming features. Just a clean list of things you need to get done.

It works exactly how you'd expect a checklist to work. You write it, you see it, you check it off.

## Features

- Craftable phone item available in survival and creative mode
- Right-click to open a task checklist
- Add tasks by typing and clicking "Add Task"
- Click any task to mark it as complete
- Clear all completed tasks with one button
- Found in the Tools and Utilities creative tab
- Lightweight, client-side mod

## How to Use

1. Craft the Task Phone or grab it from the Creative menu
2. Hold it in your hand
3. Right-click to open the checklist
4. Type your task and hit "Add Task"
5. Click on a task to mark it as done
6. Hit "Clear Done" to clean up finished tasks
7. Press Escape to close and get back to the game

## Installation

1. Install Fabric Loader for Minecraft 1.21.11 from https://fabricmc.net
2. Install Fabric API from https://modrinth.com/mod/fabric-api
3. Download the latest TaskPhoneMod .jar from Releases
4. Drop the .jar file into your mods folder
5. Launch Minecraft and you're good to go
